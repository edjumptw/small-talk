# 英語練習手冊｜日常社交 + 多益商務

線上版：https://edjumptw.github.io/small-talk/

## 內容

兩區並存，上方標籤切換：

- **日常社交** 100 句 — 破冰、寒暄、接話、收尾，10 個生活場景
- **多益商務** 100 句 — 辦公室、會議、客戶往來、出差訂位、訂單出貨、客服客訴、人事招募、財務付款、簡報報告、電話視訊，每句附「考點」而非單純翻譯

每一句底下都有一個 **「對方回」**——把對話接下去的另一半。遮起來先猜對方會怎麼答，再點開對照。多益 Part 2 考的就是這個：先問一句，再聽回應。

## 功能

- 中英文關鍵字搜尋（跨兩區，連「對方回」的內容一起找，命中字高亮）
- 👁 自測：中文、考點與對方回一起糊化，點一下掀開
- 🔊 朗讀：播放預先生成的高擬真語音，任何裝置聽到的都一樣
  - 三種聲音：美式女聲（Aria）、美式男聲（Guy）、英式女聲（Sonia）
  - 四段語速：0.7 / 0.85 / 1 / 1.15 倍，慢速時保持音高不變
  - 每句與每則「對方回」都能單獨播放
- ☆ 收藏：存在使用者自己的瀏覽器裡，可切換只看收藏
- 日夜模式切換
- 列印／存成 PDF（`?all=1` 可一次輸出兩區全部內容）

## 檔案

- `index.html` — 單檔網站，無任何外部依賴，離線也能用
- `audio/<voice>/<編號>.mp3` — 主句音檔；`<編號>-re.mp3` 為對方回音檔（共 1200 個）
- `英語練習手冊-社交+多益.pdf` — 兩區完整紙本版
- `.nojekyll` — 關閉 Jekyll，避免 GitHub Pages 誤處理底線開頭的路徑

## 更新方式

改 `index.html` 後推到 `main` 分支，GitHub Pages 約一分鐘內生效。

音檔以微軟神經語音（edge-tts）預先產生，音檔與 `index.html` 內 `DATA` 的編號（`social-001` … `toeic-100`）必須對應。
